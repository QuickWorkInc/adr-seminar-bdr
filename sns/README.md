# sns

SNS営業に関する運用、テンプレート、レビュー基準を置きます。

## 鉄の掟

SNS営業でも、各企業または各担当者ごとにパーソナライズした文面を必ず入れる。

送信禁止:

- 汎用DM
- 役職や関心テーマを読んでいないDM
- セミナー内容との接続がないDM
- 経営ベネフィット、P/LインパクトがないDM
- 苦情、返信拒否、再送禁止の記録を確認していないDM

## 必須構成

1. 相手の文脈に基づく短いフック
2. セミナー内容との接続
3. なぜ今その相手に関係するか
4. 参加ベネフィット
5. 短いCTA

## 注意

SNSでは短さが重要ですが、短さを理由にパーソナライズを削ってはいけません。
