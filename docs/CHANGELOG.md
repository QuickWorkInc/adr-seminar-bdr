# CHANGELOG

## 2026-08-04

### SendGridローカル環境変数の参照を追加
- **何を変えたか**: `.env.example` と `README.md` に `SENDGRID_API_KEY` / `SENDGRID_API_KEY_ID` の参照ルールを追加
- **理由**: SendGridを使う送信スクリプトがローカルの `.env.local` から常に同じ環境変数名でAPIキーを読めるようにするため
- **影響**: 実キーはコミットせず、ローカル環境だけでSendGrid認証情報を利用できる

### 問い合わせフォーム入力プロファイルを鉄の掟化
- **何を変えたか**: `contact/form-profile.md` を追加し、問い合わせフォームで必ず使う氏名、会社名、部署、役職、連絡先、住所、選択式項目の標準回答を明記。`contact/README.md` から必ず参照するようにした
- **理由**: 問い合わせフォーム営業で送信者情報が担当者ごとにぶれたり、毎回判断が発生したりすることを防ぐため
- **影響**: 問い合わせフォームで送信者情報が必要な場合は、竹内 智康 / 株式会社SalesNow / ADR / 事業企画 / 指定連絡先を正本として入力する

### Slack変更通知と配信ログ項目を追加
- **何を変えたか**: Slack Incoming Webhook向け通知スクリプト、`post-commit` 通知連携、Webhook用環境変数サンプル、改変詳細diff通知、配信ログ正本スプレッドシート参照を追加
- **理由**: 本リポジトリの変更内容をSlackで詳細に追跡し、アウトバウンド配信ログを指定スプレッドシートへ1配信1行で集約するため
- **影響**: コミット後にGitHub同期とSlack通知が実行され、全改変履歴と配信ログ正本シートがSlack通知本文に含まれる

### 配信ログ正本スプレッドシートを鉄の掟化
- **何を変えたか**: `seminar/delivery-log-sheet.md` を追加し、配信ログは指定Google Sheetsへ1配信1行で記録するルールを明記。ローカル `sent-log.md` は記録先ではなく正本シートへの案内に変更
- **理由**: 配信ログがMarkdown、Slack、個人メモに分散することを防ぎ、対象セミナー・配信セグメント・配信件数・配信手法・ベースメッセージを一元管理するため
- **影響**: すべての配信ログは指定Google Sheetsが正本になり、ローカルファイルへの実ログ記録は禁止になる

## 2026-07-31

### セミナー管理シートの参照を追加
- **何を変えたか**: `/seminar/management-sheet.md` を追加し、チーム利用中のセミナー管理シートURLとSheet IDを格納。`/seminar/README.md` から参照できるようにした
- **理由**: セミナー情報の正本をリポジトリ上で明確にし、開催ごとのアウトバウンド作業で参照漏れを防ぐため
- **影響**: セミナー内容の確認元が明確になり、企業別パーソナライズ文面作成時に管理シートを起点にできる

### セミナーBDRリポジトリ初期構成を追加
- **何を変えたか**: `seminar/` `email/` `contact/` `sns/` の4フォルダ、セミナー別作業場所、パーソナライズ必須ルール、GitHub同期スクリプト、検証スクリプトを追加
- **理由**: SalesNowセミナー集客のアウトバウンド営業で、メール・問い合わせ・SNSの全チャネルに企業別パーソナライズを徹底するため
- **影響**: 汎用テンプレート送信を禁止し、企業情報・セミナー内容・経営ベネフィット・P/Lインパクトを含む文面だけを運用対象にする

### GitHub同期と実キャンペーン送信前チェックを強化
- **何を変えたか**: `pre-commit` 検証、`post-commit` push、同期状態確認、実キャンペーン用 `--campaign` 検証、企業調査・文面・上位モデルレビューのテンプレートを追加
- **理由**: 未確定セミナー、企業調査なし、レビュー未承認、未同期コミットのまま運用される事故を防ぐため
- **影響**: 初期構成チェックと実送信前チェックを分離し、送信前には企業別パーソナライズ、セミナー内容接続、経営ベネフィット、P/Lインパクト、上位モデル承認が必須になる
