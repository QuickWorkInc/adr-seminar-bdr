# 20260806_claude_salesforce

2026年8月6日開催想定のClaude / Salesforce関連セミナー向け作業場所です。

## 親フォルダの鉄則

この開催フォルダ配下のすべての作業は、必ず `../README.md`、`../delivery-log-sheet.md`、`../salesnow-data-redash.md` の鉄の掟に従います。

## 作業順

1. `brief.md` にセミナー内容を確定する
2. Redash経由のSalesNowデータでターゲティング、問い合わせフォームURL、メールアドレス候補を取得する
3. `target-companies.md` に対象企業リストを置く
4. `company-research/` に各社調査メモを作る
5. `drafts/` にチャネル別の文面を作る
6. `reviews/` に上位モデルレビュー結果を残す
7. `../delivery-log-sheet.md` の配信ログ正本スプレッドシートに送信履歴を1配信1行で残す

## 鉄の掟

メール、問い合わせフォーム、SNSのどれであっても、企業ごとの文脈・経営ベネフィット・P/Lインパクトがない文面は送信禁止です。

禁止:

- セミナー概要を読まずに文面を作る
- 企業情報を読まずに文面を作る
- 社名だけを差し替えた文面を作る
- 配信ログをローカルMarkdownだけに残して済ませる
- Redashで取得できるSalesNowデータを確認せずにターゲティングする

## 配信ログ必須項目

配信ログ正本スプレッドシートには以下を必ず記録します。ローカルMarkdownへの記録で代替することは禁止です。

- 対象セミナー
- 配信セグメント
- 配信件数
- 配信手法
- ベースとして使ったメッセージ文章
