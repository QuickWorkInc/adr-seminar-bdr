# drafts

企業ごとのチャネル別文面を置きます。

命名例:

```text
<company-slug>-email.md
<company-slug>-contact.md
<company-slug>-sns.md
```

## 送信禁止条件

- 企業調査メモがない
- Redash / SalesNowデータの根拠がない
- セミナー内容との接続がない
- 経営ベネフィットがない
- P/Lインパクトがない
- 上位モデルレビューがない
- メール文面の申込URLが `https://salesnow.jp/seminars/52/?a=sn_outmail` ではない
- 問い合わせフォーム文面の申込URLが `https://salesnow.jp/seminars/52/?a=sn_form` ではない
