# reviews

設計・オーケストレーション・最終レビューを担当する上位モデルのレビュー結果を置きます。

## レビュー観点

- `model`
- `reviewed_at`
- `draft_path`
- `company_research_path`
- `decision`: `approved` / `changes_requested`
- `blocking_findings`
- `approved_by`
- セミナー内容を正しく反映しているか
- 企業情報の読み取りが具体的か
- Redash / SalesNowデータの根拠があるか
- 経営ベネフィットが明確か
- P/Lインパクトが曖昧ではないか
- 汎用テンプレート化していないか
- チャネルごとの自然さとリスクが確認されているか
