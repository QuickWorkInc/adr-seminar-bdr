# contact

問い合わせフォーム営業に関する運用、テンプレート、レビュー基準を置きます。

## 鉄の掟

問い合わせ営業でも、各社ごとにパーソナライズした文面を必ず入れる。

問い合わせフォームで送信者情報が必要になった場合は、必ず `form-profile.md` の入力値を使う。別の氏名、メールアドレス、電話番号、住所を個人判断で使うことは禁止。

フォーム文字数が短い場合でも、以下を省略してはいけません。

- 対象企業固有の文脈
- セミナー内容との接続
- 経営ベネフィット
- P/Lインパクト

## 必須構成

1. 連絡目的
2. 企業固有の文脈
3. セミナー内容との接続
4. 参加ベネフィット
5. 申込URLまたは返信依頼

## 送信者情報

- [問い合わせフォーム入力プロファイル](form-profile.md)

フォームの選択式項目で迷う場合は、`form-profile.md` の「選択式項目の標準回答」に追加してから運用します。

## 注意

問い合わせフォームは営業禁止のケースがあります。フォームの注意書きを読み、営業利用不可と明記されている場合は送信禁止です。
